# Spotify Overlay для OBS

Виджет «что сейчас играет» для стрима. Показывает обложку, название трека, исполнителя и
прогресс-бар — аккуратной карточкой поверх картинки.

Работает полностью на твоём компьютере: никаких сторонних сервисов, подписок и регистраций.
Виджет напрямую спрашивает у Spotify, что у тебя играет, и рисует это в OBS.

**Что умеет:**

- обложка альбома в пульсирующем зелёном кольце;
- название трека — если не влезает, плавно едет строкой;
- исполнители, прогресс-бар и время (текущее / общее);
- на паузе и когда музыка не играет — карточка сама скрывается;
- прозрачный фон, размытие под карточкой — ложится на любую сцену.

---

## Что понадобится

| Что | Зачем |
|---|---|
| Windows | Готовый запускающий файл `start-overlay.bat` сделан под Windows |
| [Python 3](https://www.python.org/downloads/) | Нужен **только один раз**, для первого входа в Spotify. При установке обязательно поставь галку **«Add python.exe to PATH»** |
| OBS Studio | Собственно стрим |
| Аккаунт Spotify | Подойдёт и бесплатный, Premium не требуется |

Платить за что-либо не нужно, приложение в Spotify для разработчиков бесплатное.

## Установка

### Шаг 1. Скачай файлы

Нажми зелёную кнопку **Code** → **Download ZIP**, распакуй архив в любую удобную папку.
Например: `C:\spotify-overlay`.

Важно: папку потом **не переименовывай и не переноси** — путь к файлу будет прописан в OBS.

### Шаг 2. Создай своё приложение в Spotify

Это нужно, чтобы Spotify разрешил виджету спрашивать, что у тебя играет. Пароль от Spotify
при этом никуда не передаётся.

1. Зайди на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и
   войди своим обычным аккаунтом Spotify.
2. Нажми **Create app**.
3. Заполни поля:
   - **App name** — любое, например `OBS Overlay`;
   - **App description** — любое, например `now playing widget`;
   - **Redirect URI** — вставь **ровно** это и нажми **Add**:

     ```
     http://127.0.0.1:8888
     ```

     Это самое частое место ошибки. Адрес должен совпадать символ в символ: именно
     `127.0.0.1`, а не `localhost` — `localhost` Spotify не принимает. Слеша на конце нет.
   - **Which API/SDKs are you planning to use?** — отметь **Web API**.
4. Согласись с условиями и нажми **Save**.
5. Открой у приложения **Settings**. Там будут нужны две строки:
   - **Client ID** — виден сразу;
   - **Client Secret** — откроется по кнопке **View client secret**.

   Держи эту страницу открытой, значения понадобятся на следующем шаге.

### Шаг 3. Авторизуйся

1. Запусти **`start-overlay.bat`** двойным кликом.

   Откроется чёрное окошко (это локальный сервер, он нужен только сейчас) и страница
   настройки в браузере. Если страница не открылась — обнови её клавишей **F5** или зайди
   вручную на `http://127.0.0.1:8888`.

2. Вставь на странице **Client ID** и **Client Secret** из шага 2.
3. Нажми **«Авторизоваться через Spotify»** и подтверди доступ в Spotify.
4. Тебя вернёт назад, и ты увидишь свой виджет — значит всё получилось.

   Рядом с файлами появится готовый файл **`obs-overlay.html`** — это и есть твой виджет.

5. **Закрой чёрное окошко.** Дальше сервер не нужен — ни сейчас, ни на стримах.

### Шаг 4. Добавь в OBS

1. В OBS: **Источники** → **+** → **Браузер**.
2. Придумай название, например `Spotify`.
3. Поставь галку **«Локальный файл»** — это обязательно.
4. В поле **«Локальный файл»** выбери файл **`obs-overlay.html`** из своей папки.

   Не `spotify-overlay.html` и не адрес сайта — именно `obs-overlay.html`.
5. Поставь размер: **Ширина 400**, **Высота 200**.
6. ОК. Включи музыку в Spotify — карточка появится.

Готово. Больше ничего запускать не надо: виджет сам продлевает доступ к Spotify и работает
каждый стрим.

## Как пользоваться дальше

- **Ничего не запускай.** Батник и чёрное окошко были нужны только для первого входа.
- Карточка появляется, когда играет музыка, и исчезает на паузе — это задумано, чтобы на
  стриме не висела мёртвая плашка.
- Трек на экране обновляется каждые 5 секунд.
- Если переносишь папку в другое место — поправь путь к файлу в настройках источника OBS.

### Если хочется поменять внешний вид

Открой `obs-overlay.html` любым текстовым редактором (Блокнот подойдёт) — все настройки
вида лежат в самом верху, в блоке `<style>`:

| Что поменять | Где искать |
|---|---|
| Ширина карточки | `#overlay { ... width:340px ... }` |
| Фон и прозрачность | `background:rgba(10,10,12,0.95)` — последнее число от 0 до 1 |
| Цвет прогресс-бара | `#progress-fill ... linear-gradient(90deg,#1ED760,#1DB954)` |
| Размер названия трека | `#track-name { ... font-size:22px ... }` |
| Угол, к которому прижата карточка | у `body`: `align-items:flex-end` (низ) и `justify-content:flex-start` (лево) |
| Отступ от края | у `body`: `padding:24px` |

После правок в OBS нажми по источнику правой кнопкой → **Обновить кэш страницы**.

## Если что-то не работает

**При входе Spotify пишет `INVALID_CLIENT: Invalid redirect URI`**
В настройках приложения Spotify адрес указан не так, как ждёт виджет. Должно быть ровно
`http://127.0.0.1:8888` — без `localhost`, без `https`, без слеша на конце.

**Чёрное окошко моргнуло и закрылось или пишет, что Python не найден**
Python не установлен или не прописан в системе. Поставь его с
[python.org](https://www.python.org/downloads/) и при установке отметь галку
**«Add python.exe to PATH»**, затем запусти батник снова.

**Чёрное окошко пишет, что порт занят (`Address already in use`)**
Порт 8888 занят другой программой. Либо закрой её, либо поменяй номер порта: в `server.py`
строка `PORT = 8888`, в `spotify-overlay.html` — все места, где встречается `8888`, и в
настройках приложения Spotify в Redirect URI. Номер должен быть одинаковый везде.

**В OBS пусто, хотя музыка играет**
По очереди проверь:

1. в источнике стоит галка «Локальный файл» и выбран именно `obs-overlay.html`;
2. размер источника не нулевой (400×200);
3. у OBS есть интернет — виджет каждые 5 секунд спрашивает Spotify;
4. музыка играет именно на том аккаунте Spotify, которым ты авторизовался.

**Виджет работал, а после долгого перерыва перестал**
Если Spotify долго не пользовались, он отзывает выданный доступ. Лечится повторным входом:
удали файлы `tokens.json` и `obs-overlay.html`, запусти `start-overlay.bat` и пройди шаг 3
заново. Приложение в Dashboard пересоздавать не нужно.

**Название трека не едет строкой, хотя длинное**
Строка едет только если текст не влезает в карточку. Если нужно раньше — уменьши
`width:340px` или `font-size:22px` у `#track-name`.

## Безопасность — прочитай обязательно

После авторизации рядом с файлами появятся два файла, которые содержат ключи **твоего**
Spotify:

- `tokens.json`
- `obs-overlay.html`

**Никому их не отправляй и не выкладывай** — ни в чат, ни в репозиторий, ни скриншотом.
Имея их, человек сможет обращаться к твоему аккаунту Spotify от твоего имени.

В репозитории уже лежит `.gitignore`, который не даст случайно закоммитить эти два файла.

Если ключи всё-таки куда-то утекли: зайди в Dashboard → своё приложение → **Settings** →
**Rotate client secret** (или удали приложение и создай новое), потом пройди шаг 3 заново.

Виджет не просит и не хранит пароль от Spotify и запрашивает только право **смотреть, что
сейчас играет** (`user-read-currently-playing`, `user-read-playback-state`).

## Как это работает внутри

Коротко, для любопытных:

1. `start-overlay.bat` поднимает крошечный локальный сервер (`server.py`, только стандартная
   библиотека Python, порт 8888). Он нужен **только для первого входа** в Spotify.
2. После входа сервер берёт шаблон `spotify-overlay.html`, подставляет в него полученные
   ключи и сохраняет готовый `obs-overlay.html`.
3. `obs-overlay.html` самодостаточен: он сам продлевает доступ напрямую у Spotify и каждые
   5 секунд спрашивает, что играет. Поэтому сервер после настройки можно закрыть навсегда.

Состав файлов:

| Файл | Что это |
|---|---|
| `spotify-overlay.html` | Шаблон виджета и страница настройки. Ключей не содержит |
| `server.py` | Локальный сервер для первого входа |
| `start-overlay.bat` | Запуск сервера одним кликом (Windows) |
| `obs-overlay.html` | Появится после авторизации. Личный виджет для OBS. Содержит ключи |
| `tokens.json` | Появится после авторизации. Хранит ключи |
